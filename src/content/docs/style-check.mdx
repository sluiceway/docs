## GitHub alerts

The action's Markdown uses GitHub's alert syntax. Each kind renders as a Callout.

> [!NOTE]
> A note, from `> [!NOTE]`. It takes the note look.

> [!TIP]
> A tip, from `> [!TIP]`.

> [!IMPORTANT]
> **Sluiceway is in beta.** This one comes from `> [!IMPORTANT]` and takes the pending look.

> [!WARNING]
> A warning, from `> [!WARNING]`. It also takes the pending look.

> [!CAUTION]
> A caution, from `> [!CAUTION]`. It takes the danger look.
>
> A second paragraph stays inside the same callout.

A plain blockquote stays a blockquote:

> The issue is a view and never the source of truth.

## Table

| Alert          | Callout kind | Used for                            |
| -------------- | ------------ | ----------------------------------- |
| `[!NOTE]`      | note         | A fact about how the product works. |
| `[!TIP]`       | tip          | Something that saves time.          |
| `[!IMPORTANT]` | pending      | A thing that will bite later.       |
| `[!WARNING]`   | pending      | A thing that will bite later.       |
| `[!CAUTION]`   | danger       | A delete or a replace.              |
